# Day 02 - Connecting Devices Lab

## Overview

This lab focuses on connecting Cisco network devices using the correct cable types in Cisco Packet Tracer.

## Objective

- Connect network devices according to the provided labels.
- Select the appropriate cable type for each connection.
- Understand physical network connectivity.

## Cable Types Practiced

- Copper Straight-Through Cable
- Copper Cross-Over Cable
- Fiber Optic Cable

## Skills Practiced

- Ethernet cable selection
- Physical network connections
- Network interface connectivity

## Tool Used

- Cisco Packet Tracer
