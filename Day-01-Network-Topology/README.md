# Day 01 - Network Topology Lab

## Overview

This lab focuses on creating a basic network topology using Cisco Packet Tracer.

## Objective

- Build a network topology based on the provided design.
- Add and organize network devices.
- Understand the role of different network devices.

## Devices Used

- Cisco 2911 Routers
- Cisco 2960 Switches
- Cisco ASA 5505 Firewalls
- PCs
- Servers
- Laptop used as an attacker device

## Skills Practiced

- Network topology design
- Device placement
- Basic network architecture understanding

## Tool Used

- Cisco Packet Tracer
